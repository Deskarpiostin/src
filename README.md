# Half-Life 2: Sandbox++
[![Build](https://github.com/hl2sbpp/src/actions/workflows/build.yml/badge.svg)](https://github.com/hl2sbpp/src/actions/workflows/build.yml)

This is the source code of HL2:SB++. Resources are provided at https://github.com/hl2sbpp/hl2sbpp

HL2:SB++ is a spiritual successor to HALF-LIFE 2: Sandbox, which aims to add more features than normal HL2:SB and port the game over to Android,PC and more!
